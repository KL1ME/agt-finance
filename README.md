# AGT FINANCE

Εταιρική ιστοσελίδα της **AGT FINANCE ΜΟΝΟΠΡΟΣΩΠΗ Ι.Κ.Ε.**

**Ιστοσελίδα:** https://kl1me.github.io/agt-finance/

Στατική ελληνική ιστοσελίδα με υπηρεσίες, στοιχεία επικοινωνίας και ενότητα εταιρικής διαφάνειας. HTML, CSS και JavaScript, χωρίς εξαρτήσεις, trackers ή εξωτερικές γραμματοσειρές.

## Δημοσίευση

GitHub Pages, κλάδος `main`, ρίζα `/`. Οι αλλαγές στο `main` δημοσιεύονται μέσω του GitHub Pages. Το αρχείο `.nojekyll` διατηρεί τη δημοσίευση ως στατικό περιεχόμενο.

## Τοπική προεπισκόπηση

```sh
python3 -m http.server 4173
```

Ανοίξτε http://localhost:4173.

## Ενημέρωση στοιχείων

Τα στοιχεία βασίζονται στην ανακοίνωση σύστασης Γ.Ε.ΜΗ. 197138345000/Α και στο συνημμένο καταστατικό της 01/11/2026, που παρασχέθηκαν από τον ιδιοκτήτη. Η εταιρική έδρα, ο διακριτικός τίτλος, οι ΚΑΔ και τα στοιχεία κεφαλαίου ελέγχθηκαν οπτικά στο έγγραφο.

- Τα δημόσια στοιχεία βρίσκονται στο `index.html`, μαζί με τα δομημένα δεδομένα JSON-LD.
- Ο μοναδικός εταίρος και διαχειριστής είναι ο Αθανάσιος Τσατσώνης, με 100 κεφαλαιακά μερίδια και συμμετοχή 100%.
- Η διεύθυνση εταίρου δεν αναφέρεται στο παρεχόμενο έγγραφο και χρειάζεται επιβεβαίωση από τον υπεύθυνο της εταιρείας. Δεν πρέπει να συναχθεί από την εταιρική έδρα.
- Η κατάσταση «Ενεργή», το σταθερό τηλέφωνο και το email διασταυρώθηκαν στη [δημοσιότητα Γ.Ε.ΜΗ.](https://publicity.businessportal.gr/company/197138345000) στις 17/11/2026. Το κινητό προέρχεται από την ανακοίνωση σύστασης. Η σελίδα δεν συγχρονίζεται αυτόματα με το μητρώο και πρέπει να ενημερώνεται όταν αλλάζουν τα στοιχεία.
- Το πρωτότυπο PDF, προσωπικό ΑΦΜ, στοιχεία πληρωμών και στοιχεία ηλεκτρονικής υπογραφής δεν περιλαμβάνονται στο αποθετήριο.
- Μετά τη δημοσίευση, η διεύθυνση της ιστοσελίδας χρειάζεται καταχώριση στο Γ.Ε.ΜΗ. από τον υπεύθυνο της εταιρείας. Η δημοσίευση στο GitHub δεν πραγματοποιεί αυτή την καταχώριση.

Πλαίσιο εταιρικής διαφάνειας: [Γενική Γραμματεία Εμπορίου, άρθρο 47 ν. 4072/2012](https://gge.mindev.gov.gr/tomeas-emporiou/δίκαιο-της-ιδιωτικής-κεφαλαιουχικής/).

Η ιστοσελίδα και το αποθετήριο δεν αποτελούν πιστοποίηση νομικής συμμόρφωσης. Ο διαχειριστής είναι υπεύθυνος για την ακρίβεια και την επικαιροποίηση των δημοσιευμένων στοιχείων.
